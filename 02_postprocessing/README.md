# 02 — Analysis and tables

From the repository root:

```bash
python -B 02_postprocessing/run.py --output-dir ../analysis_results
```

This recalculates the supported statistics and generates six TeX table
environments and Supplementary Data S1/S2. The new external directory contains
the outputs, a log for each step, and a PASS/FAIL summary. Supplied reference
data are not overwritten. This command needs the
[Python environment](../environment/README.md), but no GROMACS or original XTC.

| Directory | Contents |
|---|---|
| `inputs/` | Annotations, curated table cells, and trajectory-level measurements |
| `results/frame_observables/` | Derived frame measurements, not coordinate trajectories |
| `results/trajectory_summaries/` | Per-trajectory measurements used by the statistics |
| `results/aggregate_statistics/` | Reference group-level results |
| `results/tables/` | Reference tables and Supplementary Data S1/S2 |
| `results/structural_snapshots/` | Selected coordinates and snapshot indexes |
| `code/` | Statistical calculations, table generation, and validation |

Read the [data guide](DATA_GUIDE.md) for fields, units, table coverage, and
statistical definitions. See [reproduction scope](../REPRODUCIBILITY.md) for the
analyses that require original trajectories. Structural annotations and
coordinate measurements supplied as inputs are not regenerated by this command.
