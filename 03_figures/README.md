# 03 — Figures and tables

From the repository root:

```bash
python -B 03_figures/run.py --output-dir ../figures_and_tables --chimerax /path/to/ChimeraX
```

This regenerates 15 PNGs in `figures/` and six TeX table environments in
`tables/` inside the new external output directory. The table routines are
shared with 02. Supplementary Data S1/S2 are generated by 02. Table environments
require the manuscript preamble; they are not standalone LaTeX documents.

The figure directories correspond to `fig01`–`fig06` and `figS01`–`figS09`.
To render a selected figure, for example:

```bash
python -B reproduce.py --figures Figure_02 --output-dir ../figure_02
```

Structural figures (1, 5, 6 and S2) additionally require the explicit tested
ChimeraX executable. All referenced structures are included in this repository.
The complete input/output mapping is in [figures.json](../metadata/figures.json).
Historical coordinate filenames retain their source identities even when their
embedded figure number differs from the final manuscript numbering.

## TOC graphic

The independent schematic entry requires neither trajectories nor ChimeraX:

```bash
python -B 03_figures/toc/make_figure.py --output ../toc_result/TOC_graphic.png
```

See [TOC instructions](toc/README.md). The [review presentations](toc/review/README.md)
retain the historical Chinese/English PPTX comparisons separately from the
accepted schematic. They are not numerical data or final artwork inputs.

## Validation

Each renderer checks its input hashes, software/font environment, layout and
reference PNG hash. No existing final image is copied as a regenerated output.
A mismatch is a failure to investigate, not a reason to change the expected hash.
The data, thresholds, sample sizes and numerical artist values remain those
used in the manuscript. [Validation results](../metadata/TEST_RESULTS.md)
state which commands were actually run on this review export.
