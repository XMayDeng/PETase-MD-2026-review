# Historical TOC design review — 2026-09-04

- [Chinese PPTX](PETase_TOC_graphic_review_zh.pptx)
- [English PPTX](PETase_TOC_graphic_review_en.pptx)

These are unchanged independent copies of the two presentations originally in
`toc_graphic_review_20260904/outputs/` in the manuscript project. Each deck has
seven slides, speaker notes and five embedded candidate images. The files have
no external relationships or linked images and do not need the original design
directories to display their content.

The decks compare five historical V8 design options, including the candidate
created in `graphical_abstract_20260903/`. Their recommendations describe that
review, not the final author-selected V1 schematic refinement used in V9.
The current TOC code is in the parent directory and the accepted PNG is in
`03_figures/toc/TOC_graphic.png` relative to the package root.

This is a presentation-only archive, not a complete backup of the two historical
workspaces. It does not retain their PPT-generation code, graphical-abstract
source code, PDF exports, multi-format candidate exports or consultation/QA
records. Those files are not needed to open these PPTX files or reproduce the
current accepted TOC. Deleting the old workspaces would remove that additional
design history; preserving these decks alone does not preserve it.
